First release of `@parser-kit/sql`: the PostgreSQL 17 grammar that lived in the repo as the `examples/sql-lite` example, now published as a package with a dialect-first API. `postgres.parse(sql)` parses SQL into a span-annotated `Stmt[]` and throws a `ParseError` at the first problem; `postgres.diagnose(sql)` recovers at each `;` and returns `{ ast, errors }`. `postgres.parseScript(text)` and `postgres.diagnoseScript(text)` read whole psql / pg_dump scripts into `ScriptItem[]`, meta-command lines and `COPY … FROM stdin` data included. `postgres.lexer` and `postgres.scriptLexer` tokenize SQL with comments kept, for highlighters. `@parser-kit/sql/postgres` exports the `postgres` object with the AST types (`Stmt`, `Query`, `Expr`, `ScriptItem`, …), `PostgresDialect`, `PostgresTokenType` and `Diagnosis`. The package root exports the same object and types, with the AST types namespaced as `Postgres.Stmt` and so on, so that later dialects (each with its own subpath) can sit beside it without name clashes. Ships as dual ESM/CommonJS with type declarations, and depends on `@parser-kit/core`.
